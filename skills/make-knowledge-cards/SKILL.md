# Make Knowledge Cards

将输入的文章内容提炼为 5-8 张结构化知识卡片。每张卡片聚焦一个知识点。

## 输入

- 用户直接粘贴的文本
- 本地 Markdown 文件（.md）
- 本地纯文本文件（.txt）

## 输出格式

每张卡片包含以下字段，以 Markdown 格式输出：

```
### 卡片 N: [标题]

**核心知识**: 一句话概括这个知识点。

**解释**: 用 2-3 句话简明解释，保持准确，不编造原文没有的信息。

**例子/自测**: 给出一个具体例子，或一个自测问题（二选一或兼有）。
```

## 处理流程

1. **阅读全文**：完整阅读输入内容，理解整体结构和论点。
2. **提取知识点**：识别文章中真正重要的知识点，而非细节或过渡性内容。
3. **去重**：合并重复或高度重叠的知识点，每张卡片只讲一个点。
4. **撰写卡片**：为每个知识点撰写标题、核心知识、解释、例子/自测。
5. **数量控制**：目标 5-8 张。信息不足时不要强行凑数量，可以少于 5 张。
6. **忠实原文**：不编造原文没有的信息。如需补充背景，明确标注"补充说明"。

## 质量要求

- 标题简洁，不超过 15 个字
- 核心知识用一句话说清
- 解释准确，不加主观推测
- 例子具体可信，自测问题有明确答案
- 删除与核心知识点无关的冗余内容

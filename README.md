# Make Knowledge Cards

## 1. 项目解决什么问题

阅读文章后想快速提炼核心知识点用于复习，手动整理耗时且容易遗漏重点。make-knowledge-cards 将文章自动转化为结构化知识卡片，每张卡片聚焦一个知识点，包含标题、核心知识、简明解释和例子/自测问题，帮助学习者高效复习。

## 2. 主要功能

- 将粘贴的文本或本地 Markdown/TXT 文件转化为 5-8 张知识卡片
- 每张卡片包含：标题、核心知识、简明解释、例子或自测问题
- 自动提取重要知识点，合并重复内容
- 信息不足时不强行凑数量（可少于 5 张）
- 忠实原文，不编造原文没有的信息
- 不支持：网页抓取、PDF 处理、Anki 导出、图形界面

## 3. 安装方法

本项目为 AI Skill，无需安装可执行程序。将 `skills/make-knowledge-cards/` 目录放入项目即可被 AI 助手加载。

验证脚本依赖 Python 3.8+ 标准库，无需安装第三方包：

```bash
# 验证 Skill 结构完整性
python skills/make-knowledge-cards/quick_validate.py

# 运行测试用例
python skills/make-knowledge-cards/test_skill.py
```

## 4. 使用方法

### 粘贴文本

将文章内容直接粘贴给 AI 助手，说明"制作知识卡片"：

```
请把以下文章转成知识卡片：
[粘贴文章内容]
```

### 本地文件

将 Markdown 或 TXT 文件路径提供给 AI 助手：

```
请把 article.md 转成知识卡片
```

### 目录结构

```
skills/make-knowledge-cards/
  SKILL.md              # Skill 定义：输入输出格式、处理流程、质量要求
  agents/
    openai.yaml         # OpenAI agent 配置：模型参数、系统提示词
  quick_validate.py     # 结构验证脚本（纯标准库，无第三方依赖）
  test_skill.py         # 三类文章测试用例
```

## 5. 输入输出示例

### 示例一：技术教程

**输入：**

```
列表推导式是 Python 中创建列表的简洁方式。基本语法为 [expression for item in iterable]。
可以加入 if 条件过滤：even_squares = [x**2 for x in range(10) if x % 2 == 0]
列表推导式比 for 循环更快，但大数据集应改用生成器表达式。
```

**输出：**

```
### 卡片 1: 列表推导式基本语法

**核心知识**: 用 [expression for item in iterable] 语法简洁地创建列表。

**解释**: 列表推导式将 for 循环压缩为一行，先写表达式，再写循环。适合简单的列表生成场景。

**例子/自测**: [x**2 for x in range(10)] 生成 0 到 9 的平方列表。

### 卡片 2: 条件过滤

**核心知识**: 在推导式中加入 if 子句过滤元素。

**解释**: if 条件放在 for 之后，只保留满足条件的元素。

**自测**: 如何只保留 0-9 中偶数的平方？

### 卡片 3: 性能与选择

**核心知识**: 列表推导式比 for 循环快，但大数据集应用生成器表达式。

**解释**: 推导式在 C 层面优化了迭代。但会一次性生成所有元素占用内存，生成器表达式用圆括号，惰性求值更省内存。

**例子/自测**: 大数据集用 (x**2 for x in range(1000000)) 而非列表推导式。
```

### 示例二：短文本（信息不足，不强行凑数）

**输入：**

```
今天学了变量。变量就是存数据的盒子。Python 用等号赋值。
```

**输出：**

```
### 卡片 1: 变量的概念

**核心知识**: 变量是存储数据的容器，用等号赋值。

**解释**: Python 中用等号将值绑定到变量名，如 x = 10 表示把 10 存入变量 x。

**例子/自测**: x = 10 中，x 是什么？
```

> 信息不足时仅产出 1 张卡片，不强行凑数。
